# Moody: implementation plan, M2 (explore UI) ✅ (2026-10-31)

Spec: [`../specs/2026-09-28-moody-rewrite-design.md`](../specs/2026-09-28-moody-rewrite-design.md), §10–§11.

**Goal:** browse an analyzed library in the browser. That means a zoomable mood map, a list view, and track pages with the mood over time, tags, audio facts, the 2007 verdict next to the 2026 one, similar tracks and local playback. The same UI runs as a static build for the M4 Pages demo.

| # | Task | Status |

| 2.1 | API: `api/queries.py` shared by API and exporter; `/api/meta`, `/api/map` (+ top tags, 2007 octant), `/api/map/values`, `/api/tracks/{id}/neighbors` (cached EffNet cosine index), `/api/audio/{id}` (Range, library paths only) | ✅ |
| 2.2 | `moody export-static OUT_DIR`: API-shaped JSON for the static demo; round-trip tests through the API schemas | ✅ |
| 2.3 | Frontend foundation: generated API types (`npm run gen:api`, CI staleness check), `DataSource` (API + static), React Query hooks, TanStack Router hash routes, palette tokens light/dark + toggle, shared filter/selection state | ✅ |

**Verification:**
- Backend: 123 pytest tests, ruff, mypy `--strict`.
- Frontend: 24 vitest tests, eslint, `tsc`.
- End-to-end: 6 Playwright specs, stable over 3 repeats locally and green in CI.
- Visual: screenshots of map, track page and list in light and dark mode, checked for label collisions. The palette validator passes in both modes for the 3 categorical slots (all-pairs) and the ordinal ramps.

**Known limits carried forward:**
- The valence bias (spec §12) is labelled in the UI, not corrected; that's the custom V/A head's job.
- No density layer yet for very large libraries (stretch).
- Static mode has no audio until M4 adds Jamendo preview URLs.
