## M1: Analysis core

**Goal:** `moody models pull && moody scan ~/Music` produces a SQLite database with valence/arousal, a trajectory, mood probabilities, tags, DSP features and embeddings for every track. The scan is incremental and resumable.

### 1.0 Legacy import ✅
- Ported the 2007 decision tree, octant geometry, feature normalizations and k-NN to `backend/src/moody/legacy/thesis2007.py`.
- Converted the 372-song training set to `legacy/data/thesis2007_training.csv` with `legacy/convert.py`.
- Tests:
  - replay of all 32 tree leaves, plus boundary cases, against the original code
  - all 372 training labels reproduced
  - k-NN leave-one-out baseline 241/372
- The frontend circumplex uses the thesis's 8 octants.

### 1.1 Storage layer ✅
- **Deps:** `sqlalchemy>=2`, `alembic`.
- **Files:** `src/moody/store/{__init__,models,db}.py`, `backend/alembic.ini`, `backend/migrations/`.
- **Contents:**
  - declarative models for `tracks`, `analyses`, `segments`, `embeddings`, `jobs` (spec §7)
  - `open_db(settings) -> Engine` enables WAL and `foreign_keys=ON`
  - `Session` factory
- **Tests:**
  - the migration upgrade creates all tables on a temp DB
  - round-trip insert/select of a track with an analysis and segments
  - an embedding blob round-trips as a float32 `ndarray`

### 1.2 Library ingest (no ML) ✅
- **Deps:** `mutagen`.
- **Files:** `src/moody/ingest/{scan,tags,hashing}.py`.
- **Contents:**
  - `iter_audio_files(root)` finds `.mp3 .flac .ogg .opus .m4a .wav` files, skips hidden directories, and doesn't follow symlink loops
  - `content_hash(path)` is BLAKE2b over the file size plus the first and last 1 MiB
  - `read_tags(path) -> TrackTags` covers title, artist, album, duration and ISRC
  - `upsert_track()` updates the path when the hash is known (moved or renamed file) and inserts otherwise
- **Tests:**
  - fixtures built at runtime in `tmp_path`: tiny WAVs written with the stdlib `wave` module, plus tagged MP3/FLAC files committed under `tests/fixtures/tagged/` (a few KB)
  - moving a file keeps the same track id
  - an unchanged file is skipped
  - unreadable files are logged and skipped, not fatal

### 1.3 Model registry ✅
- **Files:** `src/moody/analysis/models.py`, `src/moody/analysis/models.lock.json`.
- **Contents:**
  - `ModelSpec(name, url, sha256, input, output)` entries for:
    - `discogs-effnet-bs64-1`
    - `msd-musicnn-1`
    - `deam-msd-musicnn-2`
    - `emomusic-msd-musicnn-2`
    - `mood_{happy,sad,aggressive,relaxed,party}-discogs-effnet-1`
    - `mtg_jamendo_moodtheme-discogs-effnet-1`
  - Each entry includes its `.json` metadata, which holds the class labels.
  - `moody models pull [--dir]` downloads the files, verifies SHA-256 and is idempotent.
  - `moody models list` shows present or missing status.
- **Pipeline version:** `pipeline_version()` is a hash of the lock file plus `moody.analysis.PIPELINE_REV`.
- **Tests:** download is mocked with `httpx.MockTransport`; a checksum mismatch raises an error and deletes the partial file.
- **Checksums:** the SHA-256 values are filled in by `.github/workflows/models-lock.yml` (manual dispatch). It runs `moody models pull --update-lock` on a GitHub runner and pushes `models.lock.json` to branch `chore/models-lock`. The cloud dev container can't reach `essentia.upf.edu`.

### 1.4 Analyzer ✅
- **Files:** `src/moody/analysis/{analyzer,essentia_backend,va}.py`.
- **Contents:**
  - `class Analyzer(Protocol): def analyze(self, path: Path) -> TrackAnalysis`
  - `TrackAnalysis` is a frozen dataclass with:
    - valence and arousal in [-1, 1]
    - `segments: list[(start_s, v, a)]`
    - `mood_probs: dict[str, float]` and `tag_probs: dict[str, float]`
    - `bpm`, `key`, `scale`, `loudness_lufs`
    - `embeddings: dict[str, np.ndarray]`
  - `EssentiaAnalyzer`:
    - loads the graphs once
    - reads MonoLoader at 16 kHz and runs both embedders
    - runs the heads, then the DSP at 44.1 kHz
    - imports essentia lazily, so the base install works without the `analysis` extra
  - Thesis features: `features_2007` (mode strength, harmony simplicity, tempo, rhythm regularity, loudness; 0–100) are derived from the same decode and classified with `thesis2007.classify_2007`.
  - `va.normalize(x) = (x - 5) / 4`, clipped to [-1, 1]
  - `va.smooth(series, k=3)` is a centered moving average
  - The segment start time is `i * 1.5 s` (MusiCNN hop).
- **Tests:**
  - unit tests for `va` with property tests (hypothesis): normalize is monotone, and smooth keeps length and bounds
  - a `FakeAnalyzer` for downstream tests
  - `@pytest.mark.models` integration: three synthetic 20 s clips generated deterministically with numpy (calm sine pad, loud distorted noise with a fast pulse, a mid-tempo chord loop) → assert output shapes, value ranges, BPM within ±3 for the pulse clip, and golden JSON within tolerance (golden files committed after the first run)
- **Mac check:** an M1 exit criterion is a manual run on at least 20 real tracks from the author's library, eyeballing that "sad" songs sit lower-left and "party" songs upper-right.

### 1.5 Scan job + CLI
- **Files:** `src/moody/jobs/{queue,worker}.py`, `src/moody/cli.py` (`scan` command).
- **Contents:**
  - `moody scan PATH [--limit N] [--workers N] [--reanalyze]`
    - ingest first, then analyze the tracks whose `analyses.pipeline_version` is missing or stale
    - a `ProcessPoolExecutor` with one `EssentiaAnalyzer` per process (initializer)
    - results are written from the main process in batches of 25
  - The `jobs` row tracks progress, and a Rich progress bar shows it in the CLI.
  - Ctrl-C leaves a consistent DB, and rerunning resumes.
- **Tests with `FakeAnalyzer`:**
  - a second run does no work
  - `--reanalyze` redoes everything
  - bumping `PIPELINE_REV` redoes everything
  - an analyzer exception on one file marks that track failed and the job still completes

### 1.6 Minimal read API (unblocks M2)
- **Files:** `src/moody/api/tracks.py`.
- **Endpoints:**
  - `GET /api/tracks` with cursor pagination and `q` over title/artist
  - `GET /api/tracks/{id}` returning the analysis, segments and top tags
  - `GET /api/map` as compact columnar arrays `{id[], v[], a[], tag[]}`
- **Tests:** API tests against a DB seeded via `FakeAnalyzer`.
- **CI:** export `openapi.json` and fail if it's stale, so the frontend can generate its client in M2.

### 1.7 CI: model job ✅
- Add a `models` job to `ci.yml` on `workflow_dispatch` plus a weekly schedule:
  - `uv sync --extra analysis`
  - cache `~/.cache/moody/models` keyed on `models.lock.json`
  - `moody models pull`
  - `pytest -m models`

### M1 exit criteria
- `moody scan` on the author's library of at least 1k tracks completes; its throughput is recorded in the README.
- Rerunning takes under 10 s for an unchanged library.
- All CI jobs are green, including `models`.
- `GET /api/map` returns every analyzed track.
